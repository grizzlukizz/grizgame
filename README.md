# Зона 04

Двухмерное выживание на Python Arcade. Отряд из четырёх бойцов держится
против бесконечных волн зомби на квадратной карте 3200 × 3200.

## Запуск

Понадобятся Python 3.10 или новее и графический рабочий стол с OpenGL 3.3.
Открой терминал в папке проекта.

```sh
python -m pip install -r requirements.txt
python quarantine.py
```

## Режимы

- **F2** — смена сложности в меню. Доступны «Разведка», «Выживание» и «Кошмар».
- **1** — классическая карта. Можно также начать с Enter.
- **2** — случайная карта. Генератор меняет дороги, размеры площадок и
  плотность промышленных, торговых, транспортных, парковых и охраняемых
  кварталов. Контейнеры, автобусы, баррикады, склады, ящики, киоски, клумбы
  и блокпосты различаются размерами и ориентацией. Между ними остаются
  проходы. Укрытия блокируют пули и движение. Стартовая зона свободна.
- После поражения **Enter** начинает новый матч в текущем режиме.
  В случайном режиме при этом генерируется новая карта.

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD или стрелки | Двигаться |
| Мышь и ЛКМ | Целиться и стрелять |
| 1–4 или Tab | Переключаться между живыми бойцами |
| R | Перезарядить |
| Пробел | Рывок в сторону движения или прицела. Восстановление у каждого бойца своё |
| E | Подобрать патроны или припасы |
| F | Обменять своё оружие на лежащее рядом |
| Esc | Пауза или продолжение |
| M | Вернуться из паузы в меню |

Товарищи следуют за выбранным бойцом и стреляют по видимым зомби.
После гибели бойца на месте остаются его оружие и патроны.
Если погиб управляемый боец, управление переходит к одному из выживших.
Все виды оружия используют общий тип патронов.

За убийства начисляется опыт всему отряду. На новом уровне выбери одно из
трёх случайных улучшений клавишами 1–3. Улучшения действуют до конца матча.
Между матчами сохраняется рекорд убийств.

После первой волны рядом с отрядом появляются припасы с патронами и
лечением. Каждая пятая волна заканчивается боем с усиленным зомби.
За победу над ним отряд получает дополнительный опыт и большой ящик
припасов.

## Оружейные тайники и зомби

По чётным волнам рядом с отрядом появляется оружейный тайник. Нажми **F**
рядом с ним, чтобы обменять оружие. Всего в игре десять видов оружия.
В тайниках встречаются пистолет, двустволка, штурмовая винтовка, автодробовик,
ручной пулемёт и марксманская винтовка. У каждого свои темп огня, дальность,
ёмкость магазина и время перезарядки.

Бегуны появляются со второй волны, бронированные зомби — с третьей, громилы
с рывком — с шестой. Босс завершает каждую пятую волну. Янтарное кольцо
показывает подготовку удара. Линия перед громилой или боссом показывает
направление рывка.

## Версия для Windows

Распакуй `Zone04-Windows.zip` целиком и запусти `Zone04.exe`.
Держи папку `_internal` рядом с `Zone04.exe`. В ней уже есть Python,
Arcade и остальные библиотеки. Установка зависимостей не требуется.
Запускай EXE из распакованной папки.
